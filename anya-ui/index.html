Power & memory

Switching profiles reloads the model — it takes a few seconds. “Off” frees everything.
Playing a game? The game and Anya fight over this 8 GB card, so the GPU modes get slower the harder the game pushes: measured with a game running, Turbo gave 1.8 tok/s and Balanced 2.9, while CPU only gave 11.1 tok/s and left the whole GPU to the game. CPU only does need ~3 GB of system RAM though. To hand the game everything, press Off (or set Auto-unload below).
