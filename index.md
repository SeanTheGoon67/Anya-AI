# Anya

Anya is a local AI that **chats naturally and writes code**. She runs entirely on your PC, has her own GUI with browsable chat history, a built-in RAM/VRAM limiter, web browsing, and can build real Android apps via Android Studio integration.

- **Local first**: Models run on-device (not in the cloud), caches live on S:.
- **Custom UI**: Clean interface with chat history, power profiles, Projects, and Library.
- **Web browsing**: Integrated with user control.
- **Projects**: Create Android apps, run builds, autopilot work, and manage your workspace.
- **Library**: Read whole GitHub repos into a local library and recall them in chat; export training data as JSONL.
- **Unattended working**: Keep-working loop, stop at any time.
- **Power control**: Turbo/Balanced/Lite/CPU/Off + a fine custom profile (GPU layers, context, threads).

## What Anya can do

- **Chat + code**: Ask questions, get explanations, or have her write code in fenced blocks.
- **Build Android APKs**: Scaffold a Compose app, write files, run `gradlew assembleDebug`, and get a signed debug APK.
- **Read repos**: Paste a GitHub link and she'll ingest text files into her local library, then answer from them.
- **Browse the web**: Look up current info when browsing is enabled.
- **Game-friendly**: CPU-only mode leaves your GPU free; a built-in limiter keeps resource use under control.
